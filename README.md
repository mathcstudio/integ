# 정적분 등반

고등학교 미적분Ⅰ '정적분' 단원(정적분의 계산, 위끝과 아래끝, 합·차의 성질, 구간 나누기, 절댓값, 우함수와 기함수)을 학생이 각자 태블릿에서 풀이 한 줄씩 입력하며 오르는 개인용 학습 게임입니다. 구글 스프레드시트와 앱스크립트만으로 동작합니다.

## 구성

- 등산로 입구에서 정상까지 6개 구간이 있고, 구간마다 **몸풀기 길 하나 + 도전 길 하나**를 완등하면 다음 캠프에 도착합니다.
- 문제는 부정적분 고르기 → 대입 값 입력 → 답 입력처럼 **풀이 순서대로** 입력합니다. 틀리면 힌트가 나오고, 한 줄에서 기회(기본 3번)를 다 쓰면 그 문제를 처음부터 다시 풉니다.
- **서술길**은 풀이를 세 칸에 글로 쓰면 Google Gemini가 채점합니다(기회 기본 5번).
- 캠프에 도착하면 **핵심 정리 팝업**이 나오고, 정상 직전 **마지막 관문**에서 그 내용을 빈칸으로 다시 써야 정상에 오릅니다.
- 첫 화면 아래 **관리자 모드**에서 학급별·단계별 달성률과 학생 명단을 봅니다.

## 설치

1. 새 구글 스프레드시트를 만들고 [확장 프로그램] → [Apps Script]를 엽니다.
2. `Code.gs` 내용을 모두 지우고 이 저장소의 `Code.gs`를 붙여 넣습니다.
3. HTML 파일을 `index`라는 이름으로 추가하고 이 저장소의 `index.html`을 붙여 넣습니다.
4. 스프레드시트를 새로고침한 뒤 [정적분 등반] → [처음 설정]을 실행합니다.
5. `설정` 시트에 API 키(Google AI Studio 발급)와 관리자 비밀번호를 입력하고 [채점 연결 테스트]를 실행합니다.
6. [배포] → [새 배포] → 웹 앱(실행 계정 '나')으로 배포하고, 나온 주소를 학생에게 나눠 줍니다.

코드를 고친 뒤에는 [배포 관리]에서 새 버전으로 다시 배포해야 반영됩니다.

## 시트

| 시트 | 내용 |
|---|---|
| 설정 | API 키, 모델, 기회 횟수, 정상 도전에 필요한 서술길 수, 관리자 비밀번호 |
| 등반기록 | 학생당 한 줄: 현재 위치, 도달 높이, 총점, 완등 수, 실수 횟수 등 |
| 풀이기록 | 문제마다 한 줄: 결과, 점수, 학생이 입력한 풀이, 서술형의 AI 도움말 |

API 키와 관리자 비밀번호, 서술길의 모범 풀이는 서버(앱스크립트)에만 있고 학생 화면으로 전달되지 않습니다. 선택형·입력형 문제의 정답은 학생 화면 코드에 들어 있습니다.

## 파일

| 파일 | 설명 |
|---|---|
| `Code.gs` | 앱스크립트 서버: 시트 메뉴, 기록 저장, 서술형 채점, 관리자 통계 |
| `index.html` | 학생 화면(앱스크립트에 붙여 넣는 완성본). `build.py`가 만듭니다 |
| `src/climb.js` | 구간·문제·힌트·개념 정리 데이터 |
| `src/app.js` | 화면 동작 |
| `src/app.css` | 화면 모양 |
| `build.py` | `src/`를 합쳐 `index.html`을 만드는 스크립트 |

문제나 화면을 고칠 때는 `src/`를 수정한 뒤 다음을 실행하고, 새 `index.html`을 앱스크립트에 다시 붙여 넣습니다.

```bash
python3 build.py
```

## 알아 둘 점

- 학급은 학번 앞자리로 구분합니다. 5자리는 학년 1자리 + 반 2자리, 4자리는 학년 1자리 + 반 1자리로 읽습니다.
- 학교 구글 계정에서는 웹 앱 액세스 권한이 도메인 내로 제한될 수 있습니다.
- 수식 표시는 MathJax를 jsDelivr에서 불러옵니다.
