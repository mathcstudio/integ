# 정적분 등반

고등학교 미적분Ⅰ '정적분' 단원(정적분의 계산, 위끝과 아래끝, 합·차의 성질, 구간 나누기, 절댓값, 우함수와 기함수)을 학생이 각자 태블릿에서 풀이 한 줄씩 입력하며 오르는 개인용 학습 게임입니다. 화면은 깃허브 페이지에서, 기록 저장과 채점은 구글 스프레드시트의 앱스크립트에서 동작합니다.

## 구성

- 등산로 입구에서 정상까지 6개 구간이 있고, 구간마다 **몸풀기 길 → 중간 길 → 서술길** 순서로 완등하면 다음 캠프에 도착합니다. 한 길을 완등하면 그 자리에서 다음 길을 고릅니다.
- 문제는 부정적분 고르기 → 대입 값 입력 → 답 입력처럼 **풀이 순서대로** 입력합니다. 틀리면 힌트가 나오고, 한 줄에서 기회(기본 3번)를 다 쓰면 그 문제를 처음부터 다시 풉니다.
- **서술길**은 구간마다 반드시 완등해야 하며, 풀이를 세 칸에 글로 쓰면 Google Gemini가 채점합니다(기회 기본 5번). 거듭제곱은 `x^2`처럼 씁니다.
- 캠프에 도착하면 **핵심 정리 팝업**이 나오고, 정상 직전 **마지막 관문**에서 그 내용을 빈칸으로 다시 써야 정상에 오릅니다.
- 첫 화면 아래 **관리자 모드**에서 학급별·단계별 달성률, 학생 명단, 학생이 서술길에 제출한 풀이를 봅니다.

## 구조

- **화면(프론트엔드)**: 이 저장소의 `index.html`을 깃허브 페이지로 배포합니다.
- **서버(백엔드)**: `Code.gs`를 구글 스프레드시트의 앱스크립트에 넣어 웹 앱으로 배포합니다. 기록 저장, 서술형 채점, 관리자 통계를 맡습니다.
- 화면은 `config.js`에 적힌 서버 주소로 요청을 보냅니다.

## 설치

### 1. 서버 (구글 스프레드시트)

1. 새 구글 스프레드시트를 만들고 [확장 프로그램] → [Apps Script]를 엽니다.
2. `Code.gs` 내용을 모두 지우고 이 저장소의 `Code.gs`를 붙여 넣습니다. HTML 파일은 넣지 않습니다.
3. 스프레드시트를 새로고침한 뒤 [정적분 등반] → [처음 설정]을 실행합니다.
4. `설정` 시트에 API 키(Google AI Studio 발급)와 관리자 비밀번호를 입력합니다.
5. [정적분 등반] → [AI 모델 목록 불러오기]를 실행합니다. 이 키로 실제 쓸 수 있는 Gemini 모델을 받아 와 `설정` 시트의 모델 칸을 선택 목록으로 바꿉니다. 모델을 고른 뒤 [채점 연결 테스트]를 실행합니다.
6. [배포] → [새 배포] → 웹 앱으로 배포합니다. 실행 계정은 '나', 액세스 권한은 **'모든 사용자'**여야 합니다. 로그인이 필요한 권한이면 깃허브 페이지에서 호출할 수 없습니다.
7. 나온 웹 앱 주소(`https://script.google.com/macros/s/…/exec`)를 복사합니다.

`Code.gs`를 고친 뒤에는 [배포 관리]에서 새 버전으로 다시 배포해야 반영됩니다. 주소는 바뀌지 않습니다.

### 2. 화면 (깃허브 페이지)

1. 이 저장소의 `config.js`를 열어 따옴표 안에 서버 주소를 붙여 넣고 커밋합니다.
2. 저장소 [Settings] → [Pages]에서 Source를 'Deploy from a branch', Branch를 `main` / `(root)`로 정합니다.
3. 잠시 뒤 `https://<계정>.github.io/<저장소>/` 주소가 열리면 학생에게 나눠 줍니다.

`config.js`의 주소를 비워 두면 서버 없이 화면만 동작합니다. 이때 기록은 그 기기에만 저장되고 서술길은 닫힙니다.

## 시트

| 시트 | 내용 |
|---|---|
| 설정 | API 키, 모델, 기회 횟수, 관리자 비밀번호 |
| 등반기록 | 학생당 한 줄: 현재 위치, 도달 높이, 총점, 완등 수, 실수 횟수 등 |
| 풀이기록 | 문제마다 한 줄: 결과, 점수, 학생이 입력한 풀이, 서술형의 AI 도움말 |

API 키와 관리자 비밀번호, 서술길의 모범 풀이는 서버(앱스크립트)에만 있고 학생 화면으로 전달되지 않습니다. 선택형·입력형 문제의 정답은 학생 화면 코드에 들어 있습니다.

## 파일

| 파일 | 설명 |
|---|---|
| `Code.gs` | 앱스크립트 서버: 시트 메뉴, 기록 저장, 서술형 채점, 관리자 통계. 화면은 내보내지 않습니다 |
| `index.html` | 깃허브 페이지로 배포되는 학생 화면. `build.py`가 만듭니다 |
| `config.js` | 서버(앱스크립트 웹 앱) 주소 |
| `src/climb.js` | 구간·문제·힌트·개념 정리 데이터 |
| `src/app.js` | 화면 동작 |
| `src/app.css` | 화면 모양 |
| `build.py` | `src/`를 합쳐 `index.html`을 만드는 스크립트 |

문제나 화면을 고칠 때는 `src/`를 수정한 뒤 다음을 실행하고, 새 `index.html`을 커밋합니다.

```bash
python3 build.py
```

## 알아 둘 점

- 학급은 학번 앞자리로 구분합니다. 5자리는 학년 1자리 + 반 2자리, 4자리는 학년 1자리 + 반 1자리로 읽습니다.
- 학교 구글 계정에서 웹 앱 액세스 권한을 '모든 사용자'로 고를 수 없다면, 개인 구글 계정으로 스프레드시트를 만들어 배포해야 합니다.
- 서버 주소는 `config.js`에 공개됩니다. 주소를 아는 사람은 요청을 보낼 수 있으므로, 수업이 끝나면 [배포 관리]에서 배포를 보관 처리해 닫아 두는 것이 안전합니다.
- 수식 표시는 MathJax를 jsDelivr에서 불러옵니다.
- 서술길이 필수라서 학생 한 명이 구간마다 한 번 이상 채점을 요청합니다. 한 학급이 동시에 쓰면 Gemini 무료 키의 분당 사용량 한도에 걸릴 수 있습니다. 한도에 걸리면 학생 기회는 줄지 않고 다시 제출하라는 안내가 나옵니다.
